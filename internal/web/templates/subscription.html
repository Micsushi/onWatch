      How value is calculated
      API value per full allowance
      Matched standard API value ÷ measured quota points × 100. A full weekly meter has 100 points. The estimate requires at least five points with reliably matched usage.
      Four-week output capacity
      Matched output tokens ÷ matched quota points × 400 for the same plan, model, effort, and speed. Rows marked as scaled apply a published plan ratio. Modeled rows show their evidence separately.
      Quota per attempt
      400 quota points ÷ projected four-week attempts. Attempts equal four-week output capacity ÷ benchmark output per attempt.
      Solves per subscription dollar
      Four-week output capacity ÷ benchmark output per attempt × benchmark pass rate ÷ monthly plan fee. Combined workloads give each selected benchmark equal weight per attempt. The chart and CSV use the same calculation.
      Price basis
      Subscription Value uses standard short-context API rates for comparison. The dashboard’s cost history uses rates effective when each request occurred.
